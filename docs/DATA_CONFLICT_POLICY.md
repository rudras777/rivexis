# Data Conflict Policy

Rivexis never silently selects a value when materially comparable providers disagree.

Conflict handling:
1. Confirm the providers measure the same concept.
2. Normalize units and timestamps/block heights.
3. Compare observation time and methodology.
4. Prefer the authoritative source for the specific metric, not a globally preferred vendor.
5. Preserve alternative values.
6. Reduce confidence while unexplained divergence remains.
7. Surface material conflicts in evidence and decision reasoning.

Entity-label conflicts are never silently resolved into a fabricated identity.
