## Financial and production evidence boundaries

- Deterministic protocol and failure cases use controlled RPC/API fixtures. They test real application arithmetic, isolation, failure handling and UI behavior; they do not establish current provider availability.
- Existing recorded actual Aave and bounded Morpho sequence simulations, authenticated planner alternatives and independent integer reconciliation remain the live financial evidence. These are timestamped observations, not a new audit, execution guarantee or certification of arbitrary protocols/markets.
- Coverage remains Ethereum mainnet, validated Aave V3 normal mode and the explicitly supported Morpho WBTC/USDC market. The planner explores a bounded grid, with at most two actions and a shared capital constraint across independent positions. It does not guarantee a global optimum, safety or execution.
- Native wallet permission dialogs are **not** certified by injected-provider fixtures. No private key, signature, approval transaction or transaction submission is part of these tests.
- Current DeFi report downloads are JSON evidence receipts/snapshots. A legacy PDF test is not evidence of a new DeFi PDF workflow.
- There are no fabricated points to fill historical gaps. Provider observations have source/block/time evidence; a pending wallet request is never represented as a confirmed connection.
