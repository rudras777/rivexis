# Design system

The active RIVEXIS direction is continuous royal obsidian, graphite and charcoal, ivory typography, restrained teal and bronze. Pearl light mode uses the same hierarchy and geometry. See BRAND_SYSTEM.md and the actual tokens in apps/web/app/product.css.

The landing page uses a centered editorial hero, authored layered SVG/CSS 3D risk field and consistent sections. Workspace surfaces prioritize independent protocol positions, raw evidence, explicit financial constraints, before/scenario/after comparisons and transaction-specific provenance. No probability or generic safety score is invented.

Motion responds to user input, never replaces the native cursor or scroll physics, and has touch, reduced-motion and forced-colors fallbacks. Continuous loops, third-party textures, hosted scene dependencies and extra animation runtimes are absent.

Accessibility target: WCAG 2.2 AA, semantic tables/forms, keyboard-selectable alternatives, visible focus, honest status text and non-color-only labels. Responsive layouts were tested at 320, 375, 390, 768, 1024, 1280, 1440, 1920 and 2560 pixels. Automated checks supplement actual visual review and do not certify every device.
