# Design System

Direction: white + light blue + institutional navy, high information density without crypto-neon aesthetics. Desktop-first with responsive adaptation at 1440+, 1280, 1024, 768 and mobile.

Status must never rely on color alone. Risk score, data confidence, engine confidence, decision confidence, freshness and provider status are visually separate concepts. Copy is precise and measured: “2 material risks detected” is valid; “100% safe”, “guaranteed”, “risk-free” and “AI says buy” are prohibited.

Accessibility target: WCAG 2.2 AA with semantic HTML, keyboard/focus support, accessible forms/tables, contrast and non-color-only status labels.
