# Product Definition

Rivexis — Risk • Value • Execution • Intelligence System — is institutional blockchain intelligence and crypto-finance / DeFi risk decision infrastructure. It is a decision-intelligence system, not an exchange, wallet, block explorer, generic portfolio tracker, signal service, yield aggregator or free-form AI risk scorer.

The frozen product flow is: input → data acquisition → source normalization → specialist Rivexis engines → normalized engine outputs → evidence/risk fusion → deterministic decision policy → evidence-grounded explanation → PROCEED / MODIFY / WAIT / AVOID / UNKNOWN → why + safer option → save/report/history/alert.

MVP has exactly two domains: Blockchain Intelligence and Crypto Finance / DeFi Risk, with exactly five specialist engines in each domain.
